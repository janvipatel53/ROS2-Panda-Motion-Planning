The objective of this project was to understand robotic arm motion planning using ROS2 and MoveIt2. The project focused on robot kinematics, motion planning, robot state monitoring, TF transformations, and trajectory execution using the Franka Emika Panda robot.

# Concepts 

## 1. ROS2

ROS2 (Robot Operating System 2) is a middleware framework used to build robotic applications.

It provides:

* Nodes
* Topics
* Services
* Actions
* Parameters

for communication between different parts of a robotic system.

## 2. Nodes

A node is an executable process in ROS2.

Examples used:

* hello_node
* joint_reader
* joint_monitor
* fk_monitor


## 3. Topics

Topics are communication channels used by ROS2 nodes.

Important topics used:

### /joint_states

Contains current robot joint positions.

### /tf

Contains coordinate frame transformations.

### /display_planned_path

Displays trajectories generated by MoveIt.



## 4. Forward Kinematics (FK)

Forward Kinematics calculates the position and orientation of the end-effector using known joint angles.

Input:

Joint Angles

Output:

End Effector Pose

Example:

θ1, θ2, θ3, θ4, θ5, θ6, θ7

↓

X, Y, Z



## 5. Inverse Kinematics (IK)

Inverse Kinematics calculates joint angles required to reach a desired end-effector position.

Input:

Desired End Effector Pose

Output:

Joint Angles

MoveIt automatically performs IK when a target pose is specified.

---

## 6. TF2

TF2 manages coordinate frame transformations.

Observed TF chain:

panda_link0
↓
panda_link1
↓
panda_link2
↓
panda_link3
↓
panda_link4
↓
panda_link5
↓
panda_link6
↓
panda_link7
↓
panda_hand


## 7. MoveIt2

MoveIt2 is a motion planning framework.

Responsibilities:

* IK solving
* Collision checking
* Path planning
* Trajectory generation
* Trajectory execution
